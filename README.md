## Wordell: A Wordle Clone for MS-DOS 3.3

<img src="images/logo.jpg" align="left" width="250" alt="Wordell Logo">

Wordell is a Wordle clone for MS-DOS 3.3 written in C. It features
2,315 possible unique games.

DOS 3.3 was chosen as a middle-ground between running on the most possible number of
machines while also supporting 
(Windows 1.0)[https://github.com/mpower-codeworks/WORDELL-Wordle-Clone-for-Windows-1.0]
in a future project.
